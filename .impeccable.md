# Oru design context

Oru is a calm, native-feeling desktop workspace for developers running local
or remote coding agents. The interface should support long sessions without
feeling noisy: restrained color, clear hierarchy, compact tool chrome, and
comfortable reading widths.

## Product principles

- The agent conversation is the primary surface; files, terminal, and web are
  supporting tools that remain close at hand.
- Prefer honest state and explicit labels over simulated magic. The built-in
  runtime is visibly identified as a scripted demo.
- Preserve a native desktop feel with subtle translucency, hairline borders,
  balanced density, and platform-safe drag regions.
- Support both light and dark appearances, following the operating system by
  default.
- Keep the visual language harness-neutral so Pi, Hermes, and future adapters
  can supply behavior without replacing the shell.

## Accessibility and interaction

- Maintain visible focus rings and keyboard-operable controls.
- Use a minimum 32px target for compact desktop controls and larger targets for
  primary actions.
- Do not communicate status through color alone.
- Respect reduced-motion preferences.
